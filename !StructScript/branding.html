05 — Usage Rules

✓ Do

Use the hexagonal icon mark on all official materials. Always pair it with the wordmark at small sizes. Use Teal Core as the primary action colour. Use Lime exclusively as an accent or CTA highlight.

✗ Don't

Don't stretch, rotate, or recolour the logo mark. Don't use lime as a background on large areas. Don't use the old orange palette from v1.0 — it's been retired. Don't use any font other than Manrope + DM Mono.

Minimum size

The icon mark should never appear smaller than 16×16px. The full lockup (icon + wordmark) should never appear smaller than 120px wide to maintain legibility.

Clear space

Always maintain a clear space of at least half the icon height on all sides of the logo. Never place the logo on a patterned or photographic background without sufficient contrast.
